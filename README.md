# Local C++ RAG Tool using BM25 and Ollama

## About the Project

This project is a simple RAG-based question-answering system built using C++ and Ollama. The main idea is to let users ask questions about a collection of text files and get answers based on the information available in those files.

Instead of sending all the documents directly to an AI model, the system first searches for the most relevant paragraphs using an Inverted Index and the BM25 ranking algorithm. These paragraphs are then passed to a locally running LLM through Ollama, which generates an answer using the retrieved information.

The project is an attempt to understand how traditional information retrieval techniques can be combined with local AI models to build a useful question-answering system.

## What Does It Do?

- Loads text files from a folder on your computer.
- Splits the files into paragraphs and processes their text.
- Builds an Inverted Index to find paragraphs containing relevant words.
- Uses BM25 to rank paragraphs according to their relevance to a query.
- Retrieves the top three matching paragraphs.
- Sends the retrieved context and user's question to Ollama.
- Displays the generated answer directly in the terminal.

## Technologies Used

- **C++** — Main programming language.
- **Inverted Index** — For organizing words and finding matching paragraphs.
- **BM25** — For ranking relevant paragraphs.
- **Ollama** — For running the language model locally.
- **Llama 3** — The model used to generate answers.
- **cURL** — For communicating with the local Ollama API.

### What Each File Does

- `main.cpp` — Runs the program and connects all the modules.
- `CorpusManager.h/.cpp` — Loads text files, separates paragraphs, and converts text into tokens.
- `InvertedIndex.h/.cpp` — Creates an index of words and stores their frequencies in different paragraphs.
- `BM25Ranker.h/.cpp` — Calculates relevance scores and selects the best matching paragraphs.
- `OllamaBridge.h/.cpp` — Sends the question and retrieved context to Ollama and receives its response.

## How It Works

The working process is straightforward:

1. The program loads `.txt` files from a specified folder.
2. Each file is divided into paragraphs, and the text is converted to lowercase tokens.
3. An Inverted Index is created to make keyword-based searching easier.
4. When a user asks a question, the query is processed in the same way.
5. BM25 assigns relevance scores to matching paragraphs.
6. The three highest-ranked paragraphs are selected as context.
7. The context and question are sent to the local Llama 3 model through Ollama.
8. The generated answer is displayed in the terminal.

## Getting Started

### Requirements

Before running the project, make sure you have:

- GCC/G++ installed.
- Ollama installed on your system.
- The Llama 3 model downloaded.
- cURL available in your terminal.
- A folder containing the text files you want to search.

### 1. Clone the Repository

```bash
git clone <YOUR_REPOSITORY_URL>
cd <YOUR_REPOSITORY_FOLDER>
```

Replace the placeholders with your repository details.

### 2. Download the Model

After installing Ollama, run:

```bash
ollama pull llama3
```

Make sure Ollama is running before you start asking questions.

### 3. Prepare Your Documents

Create a folder and add your `.txt` files to it.

```text
corpus/
├── document1.txt
├── document2.txt
└── document3.txt
```

The current implementation separates paragraphs using blank lines.

### 4. Set the Corpus Path

Open `main.cpp` and update the `corpusFolder` variable with the location of your documents.

For Windows:

```cpp
string corpusFolder = "C:\\path\\to\\your\\corpus";
```

For Linux:

```cpp
string corpusFolder = "/home/user/corpus";
```

### 5. Compile the Project

Run the following command from the project directory:

```bash
g++ main.cpp CorpusManager.cpp InvertedIndex.cpp BM25Ranker.cpp OllamaBridge.cpp -o rag_tool
```

On Windows, you can name the executable `rag_tool.exe` instead.

### 6. Run the Program

On Linux:

```bash
./rag_tool
```

On Windows:

```powershell
.\rag_tool.exe
```

## Example Usage

Once the program starts, you can enter a question related to your documents.

```text
Ask a question (or type 'exit' to quit): What does the document say about agriculture?

Searching for the best context...
Asking local AI...

--- AI Answer ---
The answer generated by the local model will appear here.
-----------------
```

The output will depend on the documents in your corpus and the response generated by the model.

Type `exit` or `quit` whenever you want to stop the program.

## A Few Things to Keep in Mind

- The current version supports `.txt` files only.
- Retrieval is based on matching words and BM25 ranking; semantic embeddings have not been implemented yet.
- The quality of the answer depends on the relevance of the retrieved paragraphs and the language model.
- The system does not yet provide automatic citations or guarantee that every generated answer is fully supported by the documents.
- The corpus directory is currently specified directly in `main.cpp`.

## Future Improvements

## What We've Learned

Working on this project involves applying concepts from C++ and data structures to a practical problem. It brings together file handling, text processing, hash maps, vectors, priority queues, information retrieval, and integration with a locally running language model.

It also provides a starting point for exploring RAG systems and understanding how document retrieval can help an LLM answer questions using a specific collection of information.
